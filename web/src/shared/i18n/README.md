# Localization

English (`en.json`) and Swahili (`sw.json`) are the initial UI locales.
Remember the selected language on the device and use it for OTP, notification,
voice-language hints, number/date presentation and listen/read-aloud copy.

Translations must be reviewed, short, audio-friendly and tested with local
speakers; do not machine-publish unreviewed financial, consent, safety or
security wording. SMS templates are short, and no full phone numbers or
secrets are included. The current files are only starter keys; no translated
product UI exists yet.

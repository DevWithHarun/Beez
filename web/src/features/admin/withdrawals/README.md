# Withdrawal queue

Review REQUESTED/PROCESSING records, user identity, held amount, registered
payout destination and velocity/reconciliation flags. Phase 1 admin sends
M-Pesa manually outside the app, then enters verified reference to complete
through Wallet; never claim the system has sent money automatically. Reject
requires a reason and releases hold. Require recent MFA, second admin above
the configured threshold and immutable audit. Customer/rider phone masked
unless operationally required.

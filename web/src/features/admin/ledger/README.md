# Ledger inspection

Read-only balances (sum of entries) and transaction/entry drill-down per
merchant, rider and Beez account. Show transaction reference, event, timestamp
and zero-sum check. Never provide edit/delete controls. Corrections are new
compensating/reversing entries through Wallet services with reason, MFA and
audit. Alert on any transaction not summing to zero, negative AVAILABLE
balance or daily M-Pesa mismatch.

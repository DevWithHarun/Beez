# Product and operations metrics

Read onboarding funnel, paid/completed order volume, repeat customers,
ready/accept/delivery times, cancellations/refunds, rider coverage and voice
correction rates. Label time range and source/freshness; do not present sample
values as live. Metrics are read-only, aggregated and PII-minimized. A future
read replica may serve reports; current console must call backend-owned
read models.

# Rider onboarding

Collect phone-verified identity, vehicle/plate, service area, payout phone,
private ID/selfie evidence and referee name/phone. Ask consent and explain why
each document/location field is required. Upload evidence to private storage
using scoped signed URLs. Rider remains `PENDING_APPROVAL`; only Admin may
approve/reject with reason. Do not display jobs until ACTIVE. Payout phone
changes have a proposed 24-hour delay and alerts to old/new numbers; keep as
configuration until decision is approved.
